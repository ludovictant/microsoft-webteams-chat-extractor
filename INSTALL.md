# Installation Instructions

Since this extension is not currently in the Chrome Web Store, you must install it manually as an "unpacked" extension.

## Option 1: Using the ZIP file (Recommended)
1. Download the `microsoft-teams-chat-extractor.zip` from the `dist/` folder in this repository.
2. Extract the ZIP file to a folder on your computer.
3. Open Google Chrome and go to `chrome://extensions`.
4. Enable **Developer mode** (toggle in the top-right corner).
5. Click **Load unpacked** and select the folder where you extracted the files.

## Option 2: Clone the repository
1. Clone this repository to your computer using Git:
   ```bash
   git clone https://github.com/ludovictant/microsoft-webteams-chat-extractor.git
   ```
2. Open Google Chrome and go to `chrome://extensions`.
3. Enable **Developer mode** (toggle in the top-right corner).
4. Click **Load unpacked** and select the repository folder.

---
**Note:** If you need to update the extension later, please refer to [UPDATE.md](./UPDATE.md).
